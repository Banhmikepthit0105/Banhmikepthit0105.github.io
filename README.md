# Nguyen Thanh Thai (Thomas NG) — academic homepage

Source of https://banhmikepthit0105.github.io/ — a React + Vite site deployed to GitHub Pages by `.github/workflows/deploy-pages.yml` on every push to `main`.

- Content (news, publications, experience, awards, projects, blog posts): `src/content.js` — see `CONTENT.md`.
- Paper thumbnails: `src/PaperArt.jsx`, or a real figure in `public/assets/papers/`.
- Run locally: `npm install`, then `npm run dev` and open http://localhost:5173/.
- Build check: `npm run build`.
